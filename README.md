## 👋 Sobre mí

Soy estudiante de décimo semestre de Ingeniería en Ciencias de la Computación en la Universidad Central del Ecuador, con un perfil integral enfocado en el **desarrollo de software Full Stack**, la administración de infraestructura y el soporte técnico informático.

Cuento con experiencia preprofesional construyendo e integrando soluciones web completas (frontend y backend), gestionando bases de datos relacionales, administrando redes locales y brindando soporte técnico especializado al usuario final. Me apasiona crear arquitecturas sólidas, funcionales y escalables, combinando código limpio con una excelente experiencia de usuario.

- 💻 **Desarrollo Full Stack:** Construcción de aplicaciones web de extremo a extremo (Frontend, Backend y Bases de Datos).
- ⚙️ **Backend & Microservicios:** Desarrollo de APIs RESTful, lógica de negocio y arquitectura distribuida con Java y Node.js.
- 🎨 **Frontend & UI/UX:** Creación de interfaces responsivas, intuitivas y accesibles con Vue.js, JavaScript/TypeScript y CSS moderno.
- 🌐 **Redes & Soporte TI:** Diagnóstico de hardware/software, administración de Active Directory, redes locales (LAN) y atención al usuario.
- ☁️ **Cloud & DevOps:** Despliegue de contenedores, monitoreo y fundamentos en AWS y Linux.
